## 瓶颈与挑战

1. **iOS 音频限制** — WebView 音频播放需要用户交互解锁
2. **WebSocket 稳定性** — 弱网环境下断线重连需要优化
3. **Tailscale 依赖** — 需要公网部署才能让更多人使用
4. **模型成本** — 高质量对话和 TTS 需要持续的 API 调用成本
5. **记忆容量** — 长期记忆的存储和检索效率需要优化
