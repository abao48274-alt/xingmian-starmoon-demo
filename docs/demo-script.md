## 拍摄要点

1. **真机录制** — 使用 iPhone 真机，展示实际效果
2. **流畅操作** — 提前练习，确保操作流畅不卡顿
3. **网络稳定** — 确保 Tailscale 连接稳定，避免录制时断线
4. **声音清晰** — 旁白声音清晰，背景音乐不要盖过人声
5. **字幕辅助** — 关键步骤添加字幕说明
6. **时长控制** — 严格控制在 1 分钟内
